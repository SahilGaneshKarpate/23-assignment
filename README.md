# 🤖 Machine Learning Algorithms Project

## 📌 Overview

This project demonstrates the implementation of fundamental Machine Learning algorithms for both **Regression** and **Classification** problems using Python and Scikit-learn.

The workflow includes data preprocessing, model training, prediction, performance evaluation, and comparative analysis of multiple supervised learning algorithms.

---

# 🎯 Objectives

* Perform data preprocessing and feature preparation
* Build Regression and Classification models
* Evaluate model performance using standard metrics
* Compare multiple classification algorithms
* Identify the best-performing model

---

# 📂 Datasets

### Regression Dataset

* Medical Insurance Cost Dataset

### Classification Dataset

* Breast Cancer Wisconsin Dataset

---

# 📊 Implemented Models

## Regression

* Linear Regression

## Classification

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Gaussian Naive Bayes

---

# 📈 Performance Evaluation

### Regression

* R² Score
* Prediction Results

### Classification

* Confusion Matrix
* Accuracy
* Precision
* Recall
* F1 Score
* Classification Report

---

# 📋 Model Comparison

The following classification algorithms were trained and compared:

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Gaussian Naive Bayes

Comparison was performed using:

* Accuracy
* Precision
* Recall
* F1 Score

The model with the highest overall performance was identified as the best-performing classifier.
